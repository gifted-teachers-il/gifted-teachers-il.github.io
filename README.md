# gifted-teachers-il.github.io

קהילות מקצועיות לומדות – אגף א' למחוננים ומצטיינים.

| כתובת | מה יש שם |
|---|---|
| `/` | קטלוג הקהילות (תשפ"ז) |
| `/math/` | קהילת מורות ומורי מתמטיקה למחוננים – פרטים, הרשמה ולוח מפגשים (`#schedule`) |
| `/math/meeting/` | קישור קבוע למפגש המקוון (מעביר לזום/מיט כשמגדירים `TARGET_URL`) |
| `/math/materials/` | קישור קבוע לחומרי הקהילה (מעביר לתיקייה כשמגדירים `TARGET_URL`) |
| `/assets/` | לוגואים, אייקון ותמונות שיתוף |

כרגע כל הדפים מסומנים `noindex` (לא מופיעים במנועי חיפוש) – עד שנחליט לפרסם.
